## return
функции могут использовать ключевое слово return, чтобы отдать результат
и этот результат можно будет сохранить в переменную

пример
```python
def add(a, b):
    sum = a+b
    return sum # -> return

my_sum = add(1, 7) #-> my_sum = 8

# так результат функции можно пихать куда угодно
print(add(50, 20)) # -> 70
for i in range(add(10,20)) # -> for i in range(30)
# даже вот так внутрь for
```

## append
ты уже знаешь списки -> list = [1,2,3,4,5]
их можно обрезать -> list[2:4] -> получить числа с индекса 2 до индекса 3 (последнее число(4) не входит)
так же у них есть разные функции, например, самая главная и простая append():
list.append(6) -> добивит 6 в конец списка
list.remove(6) -> удалит первую 6 которую найдём
list.clear() -> удалить весь список ( он будет = [] )

## dict
dict(словарь) - это структура данных, как и список, но он хранит ключ-значение, то есть пару, вот пример:
```python
slovar = {} # вместо [] он использует {}
slovar = {"Витя" : "лох", "Артём" : "лох", "Миша" : "крутой"}
# это не обязательно должны быть строки
slovar = {1 : "Hello", 2 : "World"}
ages = {"age1" : 12, "age2: : 18}

# это было создание словаря

# теперь добавлние и чтение:
print(ages["age1"]) # -> 12
if ages["age2"] > 10:
    print("You are older than 10")

# dict[key] -> такие квадратные скобки возвращают значение этого ключа
# !!! НО сли такого ключа нет - будет ошибка

ages.get("age3") -> если мы используем .get() то если такого ключа нет - ошибки не будет, но мы получим None

if ages.get("age3) is None: # сработает, это будет None
    print("yes") 

if ages.get("age2") is not None: # проверяем существует ли такой ключ
    print("age2 exists, it is = ", ages.get("age2") )

# добавить новых ключей
ages["age3"] = 20
ages["age4"] = 100

# for

for i in ages:
    print(i) # -> 12, 18, 20, 100

for i in ages.values():
    print(i) # -> 12, 18, 20, 100 (то же самое, только значения)

for i in ages.keys():
    print(i) # -> age1, age2, age3, age4


for key, value in ages.items():
    print(key, value) # -> age1 12, age2 18, age3 20, age4 100

for i, j in ages.items():
    print(i, j) # -> age1 12, age2 18, age3 20, age4 100

```
