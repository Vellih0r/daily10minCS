### Задание - написать свой (шифр цезаря)[https://ru.wikipedia.org/wiki/%D0%A8%D0%B8%D1%84%D1%80_%D0%A6%D0%B5%D0%B7%D0%B0%D1%80%D1%8F]
#### Шаги
1. Прочитать мой конспект
2. Написать функцию, которая будет к каждой строке добовлять ", сосал?" и возвращать результат
    ```python
    result = my_func("привет")
    print(result) # -> привет, сосал?
    ```
3. Написать словарь, который будет брать имя, и говорить игру, в которую играет человек
    ```python
    # games_dict = {...}
    name = "Миша"
    print(f"{name} играет в {games_dict.get(name)}")
    # -> Миша играет в валорант
    ```

4. Сделать функцию, которая будет брать строку, и превращать в цифры(индексы букв)
    это для шифра цезаря, как у меня на скриншоте пример
5. Понять как сдвигать все эти цифры на {ключь} вперёд
    (но если у нас последняя буква, например z имеет индекс 26 - то цифра 27 уже ничего не значит,
    так как после z нет букв, так что надо вернуться в начало, на индекс 0)
6. Взять все эти прибавленые индексы, и снова превратить в строку, уже зашифрованую, которую
    без расшифровки не получиться понять
7. Написать функцию, которая будет получать зашифрованую строку и ключ чтобы расшифровать
    и будет возвращать эту уже читабельную строку

8. задание со звёздочкой*
    можешь попробовать напистать функцию взлома, которая будет брать первые пару слов сообщения
    и будет пробовать над ним все ключи подряд (1, 2, 3, ...)
    и показывать тебе, потом ты вводишь какой ключ оказался правильным
    и тогда функция уже всё длинное длинное взломанное сообщение расшифрует этим ключём
    и это будет победа, ты взломал шифр, ура
